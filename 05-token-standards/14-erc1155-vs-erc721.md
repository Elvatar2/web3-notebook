# ERC-1155 vs. ERC-721: When to Use Which?

## Simple Definition
Choosing between ERC-721 and ERC-1155 depends on your project's needs. ERC-721 is best for purely unique, one-of-a-kind assets. ERC-1155 is best for projects that need a mix of unique items and stackable resources, or need to save gas on bulk operations.

## The Best Analogy
- **ERC-721:** Like an **art gallery**. Every painting is unique, has its own frame, and is managed individually.
- **ERC-1155:** Like a **warehouse**. You have unique antique vases (NFTs) on shelf A, and 10,000 identical boxes of screws (Fungible) on shelf B, all managed by one warehouse manager.

## Comparison Table

| Feature | ERC-721 (NFT) | ERC-1155 (Multi-Token) |
|---------|---------------|------------------------|
| **Token Types** | Only Non-Fungible | Both Fungible & Non-Fungible |
| **Contract Count** | One per collection | One for multiple collections |
| **Gas Efficiency** | Higher cost per transfer | Lower cost (supports batching) |
| **Approval Mechanism**| Per-token or operator | Per-token-type or operator |
| **Best For** | Art, PFPs, Real Estate | Gaming items, Tickets, Bundles |

## Code Example: The Gas Saving Difference

```solidity
// ERC-721: Transferring 3 different NFTs requires 3 separate transactions
// (High gas cost)
nft.transferFrom(userA, userB, tokenId1);
nft.transferFrom(userA, userB, tokenId2);
nft.transferFrom(userA, userB, tokenId3);

// ERC-1155: Transferring 3 different items requires ONLY 1 transaction
// (Massive gas savings)
uint256[] memory ids = [1, 2, 3];
uint256[] memory amounts = [100, 1, 50]; // 100 gold, 1 sword, 50 silver
erc1155.safeBatchTransferFrom(userA, userB, ids, amounts, "");
```

## Key Takeaways
- **Use ERC-721 if:** Your project is a standard NFT collection (like profile pictures or digital art) where every item is strictly unique and no batching is needed.
- **Use ERC-1155 if:** You are building a game, a ticketing system, or any project where users hold multiple types of assets and gas optimization is critical.
- **Marketplace Support:** Both are widely supported by OpenSea, Blur, and major wallets, but ERC-1155 batch transfers provide a superior user experience.
